## 🚀 Project Overview

**Excel Report Automation** is a Python-based reporting tool designed to simplify repetitive Excel reporting workflows.

Instead of manually opening multiple Excel files, combining their data, preparing a summary, formatting the final report, and sending it to stakeholders, this automation handles the workflow programmatically.

### 💡 What It Does

- 📂 Combines multiple Excel files
- 📊 Generates a structured summary report
- 🧹 Processes and organizes collected data
- 🎨 Creates clean and professional Excel output
- 📧 Supports automated email delivery
- ⚡ Reduces repetitive manual reporting work

---

## 🖥️ Sample Usage

```python
from excel_report_automation import combine_excel, send_email

# Combine multiple Excel files into a summary report
combine_excel(
    input_folder="monthly_reports/",
    output_file="summary_report.xlsx"
)

# Send the generated report via email
send_email(
    "summary_report.xlsx",
    recipients=["manager@example.com"]
)
```

## ⚙️ How It Works

### 1️⃣ Collect Excel Files

The script reads multiple Excel files from the configured input directory.

### 2️⃣ Combine Data

Data from the individual Excel files is consolidated into a single reporting workflow.

### 3️⃣ Generate Summary

The automation creates a structured summary report from the combined data.

### 4️⃣ Format the Report

The generated Excel output is organized into a clean and professional format.

### 5️⃣ Deliver the Report

The generated report can optionally be sent automatically through email.
